# 📘 AutoEngineer AI — Autonomous Software Architecture Platform

> An autonomous engineering platform that turns a one-line idea into a production-ready architecture: requirements, system design, diagrams, API specs, tech stack, cost estimates, and a sprint plan — generated by a team of 8 specialized AI agents instead of a single chatbot.

---

## ⚡ Quick Start (Local Docker Setup)

```bash
# 1. Clone repository
git clone https://github.com/autoengineer/autoengineer-ai.git
cd autoengineer-ai

# 2. Copy environment files
cp .env.example .env

# 3. Spin up multi-service Docker Compose stack
docker-compose up --build -d
```

Access services:
- **Next.js Frontend**: [http://localhost:3000](http://localhost:3000)
- **Django Core API**: [http://localhost:8000](http://localhost:8000)
- **FastAPI AI Agent Service**: [http://localhost:8001/docs](http://localhost:8001/docs)

## 🛠️ Technology Stack

| Layer | Technology | Purpose |
|---|---|---|
| **Frontend** | Next.js 14 (App Router), TypeScript, Tailwind CSS | IDE-adjacent dark UI, artifact viewer, agent timeline |
| **Backend** | Django 5 + Django REST Framework | JWT Auth, RBAC, blueprint persistence, GitHub webhooks |
| **AI Tier** | FastAPI + LangChain + LangGraph | 8-agent execution graph & generation engines |
| **Databases** | PostgreSQL 16 + pgvector, Redis 7 | Relational data, RAG vector store, event pub-sub |
| **Infra & DevOps** | Docker, Kubernetes, GitHub Actions, AWS | Multi-stage containers, HPA autoscaling, CI/CD |

---

## 🚀 What I'd Do Differently at Scale

1. **HNSW vs IVFFlat Vector Indexing**: Migrate pgvector indexing from IVFFlat to HNSW for higher query recall under high vector volume (>10M embeddings).
2. **Kafka Event Streaming**: Replace Redis Pub/Sub with Apache Kafka for immutable multi-region agent event streaming replay.
3. **Fine-Tuned Domain LLMs**: Train specialized LoRA adapters per agent persona (e.g. fine-tune Security Agent on OWASP CVE databases).
